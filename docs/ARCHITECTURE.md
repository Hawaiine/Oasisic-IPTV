# Oasisic-IPTV 架构设计

## 架构概览

```
                     ┌──────────────────┐
                     │   GitHub Cloud   │
                     │  (collect job)   │
                     │   UTC 22:00      │
                     └──────┬───────────┘
                            │ 采集结果
                            ▼
                    ┌───────┴───────────┐
                    │   Artifacts API   │
                    └───────┬───────────┘
                            │ 下载
                            ▼
                     ┌──────┴──────┐
                     │ Self-hosted │
                     │  Runner     │
                     │ (武汉联通)  │
                     │ probe-job   │
                     └──────┬──────┘
                            │ 测活+生成
                            ▼
                     ┌──────┴──────┐
                     │  git push   │
                     │  output/*   │
                     └─────────────┘
```

## 关键设计决策

### 两阶段分离（Cloud + Self-hosted）

- **collect（云端）**：纯采集，不测活，生成中间数据
- **probe（自建 runner）**：下载采集产物，武汉联通出口测活，去重选优，生成最终 M3U/EPG，推送

### 测活口径

- **唯一口径**：武汉联通出口（AS4837）
- 测活方式：HTTP HEAD + m3u8 子片段验证
- 超时：10s/源，并发 5 路

### 家宽环境说明

- IPv4 无公网仍可运行 self-hosted runner（只需出站连接 GitHub）
- IPv6 有公网可提供额外测活能力
